# Bide 1.1 — Release notes

> **Build:** 1.1.0 (2)
> **Target:** Submit to App Store Connect once 1.0 is approved.
> **Internal date:** 2026-05-28

## App Store "What's New" copy

The character-limited version (4000 char max in App Store Connect; this draft is well under). Paste verbatim:

---

Bide 1.1 grows the toolkit and tightens the trust contract.

**Eight modules now, up from four.** Screen Recordings, Live Photos, Exact Duplicates, and On This Day join the original four. Each one is focused, calm, and explains what it's doing.

**Convert a Live Photo to a still.** Keep the moment, drop the video sidecar. Saves about 40% of the file size without losing the photo. Tap the Convert button on any Live Photo; the still copies to your library and the original moves to Recently Deleted.

**Daily memory review.** The On This Day card surfaces photos from today's calendar day in past years. A calm five-minute reason to open Bide every day — not just when storage gets tight.

**Find exact duplicates instantly.** Byte-for-byte identical copies are detected in seconds via a single-pass scan, no Vision required. Catches imports and re-saves that Apple's built-in Duplicates album misses.

**Settings now shows your history.** Lifetime reclaim total + the ten most recent sessions, each with date, item count, and bytes. Everything stays on your device.

**Dashboard refreshes automatically.** When you delete photos in Photos.app or in another module, the dashboard headlines update without a manual pull-to-refresh.

**Smoother scrolling.** Thumbnail prewarming via PhotoKit's caching manager — noticeable in the Screenshots grid when you have thousands of items.

**Accessibility.** Reduce Motion is now respected throughout the app. VoiceOver labels updated on every new control.

Same promises as 1.0: no accounts, no ads, no subscriptions, no third-party tracking SDKs. Nothing uploaded by us. Every removal goes to Recently Deleted with the 30-day recovery window.

---

## Internal change log (for `CHANGELOG.md` and Confluence)

### Added

- **Screen Recordings** module — split from Large Videos. Fast clear of usually-disposable captures.
- **Live Photos** module — list by size, show video sidecar contribution, plus convert-to-still action.
- **Exact Duplicates** module — `DuplicateSignature`-based detection, signposted with OSLog.
- **On This Day** module + dashboard card — Day-of-year grouping across past years.
- **Stream-based scanning** — handles 5k–50k assets per scan via `AsyncStream`.
- **Onboarding pre-scan** — counts arrive on dashboard the instant the user grants access.
- **Lifetime reclaim tracking** — `ReclaimSession` SwiftData model + `ReclaimHistoryStore` aggregates.
- **Recent sessions list in Settings** — top 10 sessions with relative + absolute date.
- **Limited Library Access banner** — explicit support for partial-access mode.
- **iCloud "needs download" UI** — `ThumbnailView` exposes a tap-to-load affordance for cloud-only assets.
- **Screenshot OCR categorization** — `OCRClassifier` buckets by text character count (visual / mixed / text-heavy), filter chips in UI.
- **Dashboard section grouping** — Quick wins / Bulk review / Careful review.
- **MetricKit diagnostics** — `MetricsService` subscribes to MXMetricManager, payloads viewable in Settings → Diagnostics with Share affordance.
- **App icon polish** — radial gradient + drop shadow.
- **Marketing landing page** at `docs/index.html` served via GitHub Pages.
- **Live Photo convert-to-still** — `PhotoLibraryService.convertLivePhotoToStill` with two-step `performChanges` and confirmation alert.
- **Dashboard auto-refresh on library change** — `PhotoLibraryObserver` debounced + dirty-flag mid-refresh.
- **`ReviewBasket.Source` expansion** — 8 cases (one per module) so Review Basket sections route correctly.
- **Recent-capture soft badge** — Large Videos / Screen Recordings / Live Photos surface a non-blocking "Recent capture" indicator for <30-day assets.
- **In-app "How Bide works"** explainer in Settings → Help.
- **Dashboard freshness pill** — "Refreshing…" / "Updated N min ago".
- **Share Bide affordance** in Settings, personalized with lifetime bytes.
- **OSLog signposts** on Dashboard refresh phases + Similar Photos scan + Exact Duplicates detect.
- **Color asset catalog** — primary / accent / warning now light + dark variants in `Assets.xcassets/Colors/`.
- **Reduce Motion respect** — root transition and onboarding page swap gate on `accessibilityReduceMotion`.
- **PHCachingImageManager prewarming** in Screenshots grid.

### Changed

- Marketing version `1.0` → `1.1.0`, build `1` → `2`.
- Settings `Version` row reads from `Bundle.main.infoDictionary` (no more hardcoded "0.1.0").
- `PhotoLibraryService` routes thumbnail requests through a shared `PHCachingImageManager` instance.
- Docs: ROADMAP.md, safety-model.md, photokit-usage.md all current with v0.6.

### Tests

152 unit + 1 UI, up from 130 at v1.0 submission. New suites:

- `LivePhotoSummaryTests` — pure derived properties + `pairedVideoSize` fallback math.
- `RecencyRuleTests` — boundaries on <30d helper + summary integration.
- `ReviewBasketTests` additions — every Source enum case + display-name coverage + per-source grouping.

### Known constraints

- App Store screenshots have not yet been refreshed to show the new module set. Spec in `docs/app-store-screenshots-v1.1.md`.
- Localization scaffolding deferred to 1.2.
- Background scheduler for nightly pre-scan refresh deferred — not yet wired into `Info.plist` `UIBackgroundModes`.
